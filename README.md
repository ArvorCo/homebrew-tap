# Homebrew Tap for Memento

Official Homebrew tap for [Memento](https://github.com/ArvorCo/memento), the fast, local-first CPU memory engine for humans and AI agents.

## Install

```sh
brew install ArvorCo/tap/memento
memento-agent-install --agent auto --integration auto
```

The fully qualified install trusts only this formula. See the [installation guide](https://github.com/ArvorCo/memento/blob/main/docs/INSTALLATION.md) and [agent prompt](https://github.com/ArvorCo/memento/blob/main/AGENT_INSTALL.md) for all options.
